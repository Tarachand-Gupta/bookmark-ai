# Mobile app

There's a native iOS and Android app (built with Expo) that reads the same
library as the web app.

## Signing in

Sign in with the same account you use everywhere — email or **Google single
sign-on**. Once you're in, you see your library on the device.

## What you can do

- **Browse** your bookmarks in tabs.
- **Filter** with a filter sheet — narrow by category, browser, device, tag, or
  day, the same facets as the web sidebar.
- **Search** your library (hybrid search by default — keywords plus meaning).
- **Live sessions** — see the tabs open on your other devices in real time,
  when you've opted in. See [Live sessions](/guides/live-sessions).

The app has a local/production server switch for development, but for normal use
it points at the hosted service.
