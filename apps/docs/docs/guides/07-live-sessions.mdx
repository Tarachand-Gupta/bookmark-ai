# Live sessions

Live sessions show the tabs you have open **right now** on your other devices,
updating in real time. Leave a page open on your laptop and jump to it from your
phone — without saving anything.

Live sessions are **off by default** and entirely opt-in.

## Turning it on

1. In the extension popup, flip **Share window as live session**.
2. That browser starts publishing its open tabs to a dedicated live server.
3. In the app's **Live sessions** view, your devices appear with their open
   windows, each marked with a green **LIVE** pip while it's actively publishing.

The opt-in is account-wide: turning it on enables live publishing; turning it
off purges every device's live tabs immediately.

Expand the card (the chevron) and you also get **Share this window**, the
device-name field, and an **Open live tabs ↗** link straight to the app. The
explanation there is the honest summary of what leaves your browser: *"Sends the
title, address, and icon of every open tab so you can pick one up on your phone.
Private windows are never sent. Nothing is saved until you tap Save."*

## Which windows get shared

Sharing is per window, with a per-device default behind it.

- The popup's **Share window as live session** switch turns the feature on for
  that browser; **Share this window** controls the window you're looking at.
- Right after you turn it on you'll see a one-line hint — **"All future windows
  will have live sessions enabled by default. Change this behavior in
  settings."** That default is the per-device policy.
- You can change it in **Settings → Live sessions**, per device: **Enable live
  session on any new window** (on by default). Turn it off and new windows stay
  private until you opt each one in.
- If live is on but the window you're in has opted out, the popup says so:
  **"This window isn't shared"**.

## Device names

Each publishing browser shows up as a device you can **rename** (so "laptop" and
"work desktop" are easy to tell apart) or **forget**. Forgetting a device removes
its live tabs; it'll reappear if that browser is still sharing. Device names are
set in the extension popup — the field next to the switch.

From **Settings → Live sessions** you can turn sharing off entirely with the
**Show my open tabs** toggle, forget devices individually or all at once, set the
per-device new-window policy, and — behind an advanced disclosure — point at your
own **live server** if you're self-hosting.

## Picking a tab back up

A live tab is a pointer, not a saved page. From the live view you can:

- **Save** an individual tab as a bookmark, or snapshot the whole window as a
  [saved session](/guides/saved-sessions);
- **Open tabs here** straight from **Continue where you left off** on
  [your dashboard](/guides/dashboard) — with the extension installed, the whole
  window is restored in one go;
- ask about them in [Ask AI](/guides/ask-ai), which can see your live tabs as
  well as your library.

## Privacy guarantees

Live sessions are built to be private by default:

- **Opt-in only.** Nothing is shared until you turn it on, per account.
- **Private/incognito windows are never sent.**
- **URLs that look credential-bearing are reduced to their origin** before
  leaving your browser, so a link with a token in it isn't broadcast in full.
- **Ephemeral.** Live tab data expires automatically after **7 days** of a
  device going quiet (the timer resets each time the device checks in). There is
  no long-term store of your open tabs.
- **Nothing is saved until you save it.** Live tabs are a mirror, not a
  bookmark. To keep a tab, save it as a bookmark or snapshot the window as a
  [saved session](/guides/saved-sessions).

See [Privacy](/privacy) for the full picture, and
[self-hosting the live server](/self-hosting/live-server) if you want to run it
yourself.

:::warning
Live sessions and saved sessions are different things. Live sessions are
temporary and expire; saved sessions are permanent snapshots you take on
purpose.
:::
