# Install the extension

Saving happens through the browser extension. It's built for Chrome, Firefox,
and Safari from one codebase.

1. Install the Bookmark AI extension for your browser.
2. Open the popup and sign in. The extension **mirrors the session from the web
   app** — sign in on [bookmark-ai.cloud](https://bookmark-ai.cloud) and the
   popup picks it up. There's no separate sign-in inside the popup, because
   browsers don't allow OAuth flows there.
3. Once signed in, the popup shows your name and the save controls.

:::note
Signing out from the extension popup ends the shared session, so it signs you
out of the website too — they are the same session.
:::

## Keyboard shortcut

Press **Alt+Shift+S** to open the popup without reaching for the toolbar.
