# The onboarding tour

The first time you open the app, a short tour introduces each feature. It walks
through, in order:

1. **Set up your AI** — connect a provider so chat and answers work. OpenRouter
   is suggested as the quickest start because it has free models. See
   [AI providers](/guides/ai-providers).
2. **Save from any browser** — install the extension; one click saves and
   auto-categorizes a page.
3. **Search by meaning** — how search blends keywords with meaning, and how
   **Ask AI** answers with citations.
4. **Live tabs** — opt in from the extension to mirror your open windows across
   devices. Nothing is stored until you save it.
5. **Saved sessions** — snapshot a whole window and restore it later.

You can step through or skip it — nothing here is required to start saving. Each
topic has a full page under [Guides](/guides/saving-bookmarks).
