# The onboarding tour

The first time you open the app, a short tour introduces each feature. It walks
through, in order:

  alt="The first-run onboarding tour dialog, open on the 'AI setup' tab with the OpenRouter preset selected."

  light="/img/screenshots/onboarding-light.jpg"

1. **AI is included, free** — nothing to set up: chat and answers run on the
   shared AI with free credits every week. The step is about the optional
   upgrade — plugging in your own provider key, which runs unmetered on the
   model you pick. See [AI providers](/guides/ai-providers).
2. **Save from any browser** — install the extension; one click saves and
   auto-categorizes a page.
3. **Snapshot a whole window** — saved sessions: capture every tab as one item
   and bring them all back later.
4. **See open tabs across devices** — opt in from the extension to mirror a
   window's tabs in real time. Opt-in only, and a live session disappears after
   7 days.
5. **Find it by what it means** — how search blends keywords with meaning, and
   how **Ask AI** answers with citations.

You can step through or skip it — nothing here is required to start saving. Each
topic has a full page under [Guides](/guides/saving-bookmarks).

## Three more things worth knowing

The tour doesn't cover everything. If you're finding your way around:

- **[Your dashboard](/guides/dashboard)** is the page you land on. It picks up
  where you left off, shows recent saves and your reading list, and quietly
  drops cards that have nothing to say.
- **[The library](/guides/library)** is where filtering lives — categories,
  tags, browsers, devices, and date ranges down to the last hour — plus bulk
  select for deleting or exporting a set of rows as CSV.
- **[MCP](/guides/mcp)** connects an AI agent, such as Claude or Cursor,
  straight to your library, so it can search and save on your behalf.
