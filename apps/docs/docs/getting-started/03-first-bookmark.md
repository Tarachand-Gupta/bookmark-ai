# Save your first bookmark

1. Open a page you want to keep.
2. Click the Bookmark AI extension (or press **Alt+Shift+S**).
3. Click **Save**.

That's it. Behind the scenes the app:

- reads the page and scrapes its **Open Graph** data (title, description, image),
- sorts it into a **category** and assigns **tags** — no folders to maintain,
- builds a **semantic embedding** so the page is findable by meaning.

The save returns immediately — the heavier AI work runs right after, so the
page is searchable moments later.

:::note
Bookmarks are keyed by URL. Saving the same page again updates it rather than
creating a duplicate, and re-runs categorization and embedding.
:::

Open [bookmark-ai.cloud](https://bookmark-ai.cloud) and your new bookmark is in
the library, filed under its category with its tags. From here you can
[search](/guides/search) or [ask AI](/guides/ask-ai) about it.
