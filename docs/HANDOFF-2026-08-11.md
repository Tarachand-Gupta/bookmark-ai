## 4. Process rules this cycle burned in (also in memory/CLAUDE.md files)

- A revert NEVER frees a migration version number — take the next number after the highest
  ever recorded in prod (v9 collision cost a prod outage of the MCP token routes).
- Agents never bare-`vercel deploy` from the repo root (the root link is the WEB project).
  Docs deploy needs repo-root + explicit VERCEL_ORG_ID/VERCEL_PROJECT_ID.
- Bare `wxt build|zip|prepare` hangs forever after success (Clerk module-scope handle) —
  always `scripts/wxt-run.mjs`; it also skips prepare on Vercel.
- QA fixtures must be production-reachable states (no phone "live devices"); track created
  ids for cleanup, never delete by pattern-match; prefer headless-shell for signed-in QA
  (a headed window once caught stray input from the real display).
- Two dev servers must never share `apps/web/.next`.
